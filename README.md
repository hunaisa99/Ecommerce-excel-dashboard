# E-Commerce Sales & Profitability Dashboard

An interactive dashboard designed to analyze e-commerce sales performance, profitability, customer segments, products, and sales channels.

## Key Insights

- Monthly sales trend analysis
- Customer-wise revenue analysis
- Top and bottom performing products
- Order size and order value analysis
- Sales channel performance
- Customer segment analysis
- Revenue and profitability comparison
- Identification of high-performing and low-performing products

## Dashboard

The dashboard provides a visual overview of e-commerce business performance and helps identify important sales and profitability trends.
